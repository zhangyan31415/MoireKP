# Aligned hBN / bilayer graphene

This example retains one hBN layer and two graphene layers in an orthogonal,
spinless TAPW basis. Six radial shells contain 27 hBN reciprocal vectors and
37 vectors for each graphene layer. The B/N and A/B orbital labels give
`2*27 + 2*2*37 = 202` basis states per valley. Both materials remain explicit.

The input is a numerical Slater-Koster Hamiltonian in eV. The example does not
require an OpenMX calculation or eliminate the hBN orbitals.

## Installation and data

Create the project environment from the repository root:

```bash
conda env create -f environment.yml
conda activate moirekp
```

The GitHub checkout includes the prepared `inputs/` and `reference/`
directories. After installation, run the commands below directly. No separate
data download is required. Generated outputs remain excluded from version control.

If preparing the original reference data instead, place its `POSCAR`, `H.dat`
and `tapw/Q_shell_6/` results under a directory named `source_data`, then run
from this example directory:

```bash
python prepare_inputs.py --source source_data
```

Preparation records checksums and paths relative to the supplied source root.
It preserves the 19,268-site source order and eV matrix elements. Old NPZ caches
are not reused because they may already contain a basis permutation.

As in the other TAPW examples, `system.structure` is a rigid reference
(`inputs/POSCAR_rigid`), while the source Hamiltonian retains the relaxed
structure's hopping values. The original coordinates are preserved separately
in `inputs/POSCAR_relaxed`. The rigid reference preserves atom order and the
supercell, keeps hBN fixed, and reconstructs ideal graphene sheets at their
original mean heights. It is not a newly calculated rigid-structure Hamiltonian.

The normal preprocessing path identifies the primitive cells and sublattices
from this reference. `cluster.spglib_symprec: 0.001` specifies its distance
tolerance in Angstrom. It is independent of `symmetry.spglib_symprec`, which
controls symmetry analysis. No basis-label file or custom runtime wrapper is
needed. Configurations that omit the preprocessing setting retain the previous
default, so the other examples' defaults are unchanged.

## Run the band example

From this example directory:

```bash
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1
mkdir -p verification
python -m tapw.cli run -c config.yaml > verification/K1.log 2>&1
python -m tapw.cli run -c config_K2.yaml > verification/K2.log 2>&1
python verify_results.py
python plot_results.py
python plot_basis.py
```

Each configuration uses four k-point workers and one BLAS/OpenMP thread per
worker; adjust `bands.num_processes` to the resources available. Both band
paths contain 61 k points and return all 202 eigenvalues at each point.

The runtime onsite parameters match the reference calculation: external slope
`0.01 eV/Angstrom`, internal symmetric slope `0.005 eV/Angstrom`, and
zero-potential layer indices `[1,2]` (zero based). These onsite terms act on the
explicitly retained source atoms. The supplied numerical Hamiltonian is the
reference input; its SK parametrization and structural relaxation are not
regenerated by this example.

## Results

- `outputs/K1_spinless/q06/band/` and `outputs/K2_spinless/q06/band/`: energies,
  k points and retained reciprocal vectors.
- `verification/summary.json`: basis/vector/k-path checks and raw differences
  from the archived relaxed-coordinate projection, with no energy alignment;
  full-spectrum and +/-150 meV statistics are reported.
- `verification/selected_vectors.csv`: material, valley, shell and G/Q coordinates.
- `verification/band_comparison.pdf`: current/reference band overlay.
- `verification/appendix_figure/`: the three-panel basis figure and individual panels.

The archived comparison uses relaxed coordinates for the projection, whereas
the standard example uses a rigid reference, including for the runtime onsite
field coordinates. Their energy differences are reported as a diagnostic,
not an identical-basis regression; the observed maximum over both valleys is
about 0.48 meV.
No energy alignment is fitted. An optional `--energy-tolerance-mev` argument
enforces a user-selected bound against that legacy result. A common
reciprocal-origin offset of about
`1.13e-5 Angstrom^-1` from the original primitive-cell fit is reported separately;
the vector sets agree after subtracting it. Band energies are not shifted.

This is a band-path reproduction example, not a cutoff-convergence study.
It does not establish the historical quantum-geometry mesh or reproduce the
full manuscript survey. Single-`pz` inputs are validated here for spinless
band calculations; full orbital-symmetry workflows are outside this example.
